# Видео-анализ: карты, победа этажа, смерть, продолжение

Кадры: scratchpad/frames/<clip>/f_NNN.jpg. t = старт клипа + (N-1)/fps. Оценки ±1 кадр.

## 1. cards_spin (00:12, 8fps, 32 кадра ≈ 4 с)
- 0.0 с (f_001): экран «VICTORY! / Floor 1 Cleared!» поверх боя.
- ~0.25 с (f_002–003): переход на «Choose One» (кроссфейд ~0.2 с), появляется подзаголовок «◆ BIG REWARD INCOMING ◆» (мигает/пульсирует).
- f_003–f_025 (~0.25–3.0 с): спиннер. Имена всех 3 карт меняются каждый кадр (≥8 раз/с), рамка карты меняет цвет вместе с редкостью кандидата (серый / зелёный / синий / фиолетовый / золотой). Текста описаний нет — только имя по центру. Длительность ≈ 2.7 с.
- Замедления в кадрах явно не видно (смена каждого кадра до конца) — либо оно короче 0.25 с.
- ~3.0 с (f_025): «BIG REWARD INCOMING» исчезает; карты фиксируются слева направо почти одновременно (f_025–f_027): появляется строка редкости сверху, описание, строка stacks.
- Финал (f_027+): Serrated (Common), Reckless (Uncommon, зелёная рамка + зелёное свечение-ореол при hover), Padding (Common). Наведение: карта подсвечивается glow, без заметного масштаба.
- Средняя карта во время спина показывает «•»-курсор — это мышь, не элемент UI.

## 2. cards_pick (00:50, 6fps, 36 кадров ≈ 6 с)
- 0.0 с: удар, всплывает «+1 COPPER KEY!» у врага (жёлтый пиксельный шрифт).
- ~0.3–1.3 с: «VICTORY! Floor 2 Cleared!» (держится ~1 с).
- ~1.5 с (f_009): «Choose One», карты появляются полупрозрачными (fade-in ~0.3 с); первый кадр показывает «Shield Bash» блёкло — карты стартуют сразу с именами.
- ~1.6–3.3 с: спин (≈1.8–2 с), без «BIG REWARD INCOMING» (появляется не каждый раз — вероятно, только при гарантированной высокой редкости/на особых этажах).
- ~3.5 с (f_021–023): фиксация: Leech, Tempering, Shield Bash (все Common, серые рамки). Похоже, карты останавливаются последовательно (лев. → прав., шаг ~1 кадр = 0.17 с).
- Дальше курсор водит по картам; клик в клипе не виден (клип кончается до выбора).

## 3. floor_victory_key (00:09, 8fps, 24 кадра = 3 с)
- 0.0–0.4 с: последний удар, урон «18» белым над врагом, враг исчезает.
- ~0.9 с (f_008): вспышка — полноэкранный жёлтый оверлей (~70% альфа), 1 кадр; затем фейд ~0.25 с.
- f_008–f_015 (~0.9–1.8 с): золотой ключ появляется у места врага (≈x 0.6 экрана, y 0.35), покачивается/вращается и плавно падает вниз на ~10% высоты; рядом текст «+1 GOLD KEY!».
- ~1.9 с (f_016): ключ затухает; сверху проявляется «VICTORY!» (scale/slide-in сверху, ~0.25 с), далее «Floor N Cleared!».
- Ключ НЕ летит в HUD — просто исчезает на месте.

## 4. death (02:33, 4fps, 28 кадров = 7 с)
- 0.0 с: Floor 8, бой, враг-скелет; при попадании враг мигает белым силуэтом (hit flash 1 кадр). Урон «26», затем по герою «16» (красный).
- ~1.0 с (f_005): резкий переход на «You Died» (фон — тёмный лес с замком, луна; фейд ≤0.25 с).
- Экран: «You Died» (красный), «Reached Floor 8», «Best: Floor 8», строка «Keys · 1 copper · 1 silver · 1 gold», «Ranking...» → через ~2.5 с меняется на «Your rank: #6287 of 7757». Кнопки: REVIVE [иконка видео] (подпись «Floor 6 · …»), Main Menu, PLAY AGAIN.
- f_028 (~6.75 с): после Main Menu — главное меню с кнопкой Continue «Floor 6 · your loadout».

## 5. revive_continue (03:34, 8fps, 24 кадра = 3 с)
- 0.0–1.4 с: главное меню, клик Continue (f_011).
- ~1.5 с (f_012): затемнение (~0.15 с) → текст «Descending to Floor 6...» сверху.
- 1.6–2.6 с: имена перков вылетают и разлетаются по экрану (зелёные/голубые: Reckless, Leech, Stoneblood, Whetstone, Spark…), затухая — «восстановление билда».
- ~2.75 с (f_022): бой Floor 6, баннер «Floor 6» + подпись врага, затем «You strike first!».
Итого: Revive = рекламная кнопка на экране смерти, а Continue в меню продолжает с N-2 с сохранённым loadout.

## Новая информация
- Новые имена карт: Titan, Juggernaut, Assassinate, Vitality, Brutal, Bulwark, Honed Edge, Serrated, Splinters, Vampirism, Bandage, Hamstring, Deadly, Smack, Aegis, Cull, Deathwish, Ironclad, Catch Breath, Duelist, Bloodlust, Momentum, Spark, Bloodforge, Keen Eye, Godblade, Barbs, Reckless, Padding, Tempering, Trophy, Shield Bash, Bloodbound, Reaper, Whetstone, Leech, Stoneblood.
- Тексты: Serrated (Common) «+0.3 Crit Damage», Crit dmg ×2.0→×2.3 (stacks). Reckless (Uncommon) «+22% Attack, -12% Max HP», Atk 12→15 · HP 100→88. Padding (Common) «+8 Defense», Def 20→28. Leech (Common) «Heal 8% of damage dealt», Lifesteal 0→8%. Tempering (Common) «+12% Defense», Def 20→22. Shield Bash (Common) «+3 Defense; 20% of Defense adds Attack», Def 20→23 · +6 atk from def.
- Цвета редкости рамок: Common серый, Uncommon зелёный, Rare синий, Epic фиолетовый, Legendary золотой (по спину). Во время спина рамки рандомны — цвет идёт вместе с именем кандидата.
- Строка «(stacks)» — превью до→после.
- «BIG REWARD INCOMING» — новый подзаголовок.
- Экран смерти с рангом, меню с сезоном/лидербордом, «Descending to Floor N» с разлетом перков — новое.
- Ключи: copper / silver / gold, падают с врагов; gold — со вспышкой экрана.

## Вопросы
- Есть ли замедление спина (ease-out) — нужен 30–60 fps клип.
- Порядок фиксации карт точно (одновременно или по очереди).
- Условие показа «BIG REWARD INCOMING» и меняются ли шансы редкости.
- Анимация клика/выбора карты и переход в бой — не попала в клипы.
- Использование замка (lock) и реролла по рекламе — не показано.
- Где точно применяется Revive (на экране смерти) vs Continue — оба ли дают N-2.
