# Dungeon Descent — выбор карт (бонусов) и главное меню: заметки по скриншотам

Все скрины 1920x1080 (захват CrazyGames: снизу полоса портала ~4% высоты (y 96–100%) — "Dungeon Descent", "Hide this bar", лайки 1K и т.п.; это НЕ игра. Игровая область по бокам обрезана чёрными полосами x 0–2% и 98–100% на большинстве скринов карт; на cardsTypes_3/4/5 и в меню полос нет — разный масштаб окна).
Рулетки/спиннера (spinner) ни на одном скрине НЕТ. Иконок на картах НЕТ — карты чисто текстовые.

## 1. По скриншотам

### card_select_screen_prepare.png — карты появляются (до раскрытия)
- Фон: тёмная стена подземелья из камня, цепи, факелы с оранжевым свечением слева/справа, слева знамя с черепом. Затемнена виньеткой.
- Сверху по центру (y ~6%): золотой орнамент-разделитель с медальоном-черепом (ширина ~15% экрана).
- Заголовок "CHOOSE ONE" (y ~14%, высота букв ~8%), золотой градиент (жёлто-оранжевый), капитель-шрифт с засечками (Cinzel-подобный), свечение.
- Малый разделитель (y ~22%).
- Баннер "✷BIG REWARD INCOMING✷" (y ~25%), золотой, меньше. Только на этом скрине → вероятно, анонс редкого/легендарного выбора (в т.ч. есть золотая рамка).
- 3 карты: x центры ~25%, 50%, 75%; y 30–80%; размер ~20% x 49% экрана. Рамки: левая ЗОЛОТАЯ (legendary?), средняя ЗЕЛЁНАЯ (uncommon), правая СЕРАЯ/серебряная (common). Внутри только название по центру (y ~47%) белым капитель-шрифтом и разделитель под ним; описания ещё нет (анимация раскрытия/печати текста).
  - "SPARK" (золотая рамка), "SHIELD BASH" (зелёная), "REINFORCE" (серая).
- У каждой карты в правом верхнем углу — иконка открытого замка (серый навесной замок, ~2% ширины) → функция «закрепить карту» перед рероллом.
- Снизу (y ~91%): текст-кнопка "REROLL - WATCH AD" светло-голубой (#7fc0ff-подобный) капитель-шрифт, без подложки.
- Правый верх (x ~90%, y ~6%): круглая кнопка статистики (иконка столбцов, золотое кольцо, тёмный фон, Ø ~4.5% ширины).
- Правый низ (x ~95%, y ~90%): круглая кнопка настроек (шестерёнка, золотое кольцо, Ø ~4.5%).
- Курсор — стандартная стрелка.

## 3. Механика (выводы)
- Каждый выбор: ровно 3 карты, взять 1. Редкость каждой карты роллится независимо (в одном наборе бывают разные). Дубли в одном наборе не видны.
- Стартовый выбор "CHOOSE YOUR PATH" перед первым этажом — без реролла; все 3 Uncommon (возможно, стартовый пул фиксированной редкости).
- Обычный выбор "CHOOSE ONE" (после боя/этажа) — с кнопкой "REROLL - WATCH AD" (rewarded-реклама → в Poki: rewardedBreak). Замок на карте — закрепить карту, чтобы она осталась при реролле (гипотеза).
- "BIG REWARD INCOMING" — особый выбор (после босса?), гарантирует высокую редкость (золото=Legendary).
- Редкости: Common (серебро/серый), Uncommon (зелёный), Rare (синий), Epic (фиолетовый), Legendary (золотой, гипотеза). Цвет: рамка + свечение за картой + текст редкости + название (кроме common).
- Ценность растёт с редкостью (Serrated 0.3 → Brutal 0.9; Hamstring 10% → Executioner 26%).
- Строка-превью «текущее→новое» считается от текущих статов героя; маркер (STACKS) — суммируется, (REPLACES) — заменяет предыдущий эффект того же типа (execute).
- Базовые статы на старте: ATK 12, DEF 12, HP 100, Crit 8%, Crit DMG ×2.0.
- Главное меню: Continue (если есть сейв; подпись «Floor N - your loadout») → экран «Descending to Floor N...» с анимацией перков → бой. Play — новый забег (→ Choose Your Path). Inventory, Settings, Leaderboard (сезонный, общий сид этажей: «one dungeon - everyone races the same floors»). Ключи 3 типов (бронза/серебро/золото) — валюта сундуков инвентаря.

## 4. Ассеты (плейсхолдеры)
Вырезать со скринов как временные:
- Рамки карт ×5: серая (common), зелёная, синяя, фиолетовая, золотая — орнаментальные с ромбами сверху/снизу и завитками в углах; внутренность — тёмный сине-чёрный пергамент с шумом. Лучше: одна рамка + tint по редкости (CSS/фильтр) + 9-slice.
- Свечение за картой (радиальный градиент по цвету) — делать кодом.
- Разделители-орнаменты: большой с медальоном-черепом, малый, разделитель внутри карты.
- Иконка замка (open/closed — closed не видна), кнопки «статистика» и «настройки» (круг с золотым кольцом).
- Фон экрана выбора (стена подземелья с факелами) — AI-генерация.
- Главное меню: фон (ночь, луна, ворота), герой в бирюзовом плаще — AI-генерация; логотип "Dungeon Descent" + медальон-череп — AI/своё название DungeonJourney; кнопки-плашки (изумруд + золото, 3 размера) — 9-slice, вырезать/сгенерировать; иконки ключей ×3; медали лидерборда; скрещённые мечи.
- Шрифт: заголовки/текст — Cinzel (Google Fonts) или Cinzel Decorative для лого; всё капителью (small-caps). Кнопки Continue — обычный регистр (Cinzel bold). Цвета: золото #f5c542→#e08a1e градиент, кремовый #efe6d0, голубой реролл #8cc8ff.
- UX-проблема (обязательно исправить в клоне): тексты длинные и переполняют карту —
  - "EXECUTIONER" вылезает за правый край рамки;
  - "+20% CRIT; CRITS HEAL 40% OF DAMAGE", "EXECUTE FOES BELOW 10% HP; +5 ATTACK", "INSTANTLY KILL FOES BELOW 26% HP; +25 ATTACK" — 3 строки, налезают на разделитель;
  - "THORNS 60% · MAX 10% ENEMY HP · (STACKS)", "CRIT 11→31% · CRITS HEAL 40% · (STACKS)" — превью в 2 строки.
  → авто-ужатие шрифта (fit-text), фиксированные зоны, сокращать текст; на мобильном (портрет) карты ещё уже — критично.
