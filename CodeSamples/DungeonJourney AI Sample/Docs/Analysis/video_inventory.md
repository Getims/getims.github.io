- Salvage: Common = ◆2, Uncommon = ◆3. 10◆ = 1 copper key (прогресс «Shards N / 10 → copper key»).
- Апгрейд ◆: Common стоит 8, Uncommon стоит 12. Эффект «+1 (+10% stats)». Не нажимали.
- Merge: «1/3 copies» = нужно 3 одинаковых, результат +1 уровень. Не выполнялся.
- Ключи: 1/1/1 → 0/0/0. Обмен 3→1 не выполнялся.
