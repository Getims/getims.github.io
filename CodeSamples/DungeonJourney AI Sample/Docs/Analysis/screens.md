# Dungeon Descent: заметки по скриншотам (экраны Build / Settings / Win / Fail)

Все скрины 1920x1080. Внизу полоса CrazyGames (y 96-100%), это не часть игры. Игровое поле примерно x 2-98%, y 0-96%.
Шрифт UI: антиква с капителью (small caps), похоже на Cinzel / Cormorant SC. Заголовки золотые с градиентом и свечением. Текст в бою ("You", "Best:", "Keys", имя врага) моноширинный, похоже на Courier. "You Died" написан готическим/blackletter-шрифтом, красный с тёмной обводкой.

## 2. Выведенная механика

### Статы
- MAX HP: максимальное здоровье. База 100.
- ATTACK: урон за удар. База (этаж 1) 12. Эффективная атака = ATTACK + floor(DEFENSE × 0.30) при наличии DEF → ATK: 12 + 20×0.3 = 18; 62 + 27×0.3 = 70.1 → 70 (+8); 73 + 46×0.3 = 86.8 → 87 (+14). Значит округление round: 8.1→8, 13.8→14.
- DEFENSE: снижение урона в процентах. Блок = DEF/(DEF+K). 20→31%: K≈44.5; 27→38%: K≈44; 46→51%: K≈44.2. Вывод: block = DEF/(DEF+45)?: 20/65 = 30.8% → 31, 27/72 = 37.5% → 38 (round), 46/91 = 50.5% → 51. Подходит K = 45 (с округлением). Урон по герою = dmg × (1 − block).
- CRIT: значение = шанс в % (31 → 31%), множитель x2.0 (возможно, повышается картами).
- LIFESTEAL: % от нанесённого урона лечит (может быть дробным, 34.3).
- THORNS: отражает N% урона от каждого удара врага обратно, но не больше 25% от макс. HP врага за удар.
- EXECUTE: врага ниже 26% HP мгновенно убивает. Порог задаётся картой, карты заменяют друг друга, не складываются.
- DEF → ATK: 30% защиты прибавляется к атаке (дано, видимо, стартовой картой STONEBLOOD или героем).
Строки статов с нулём (LIFESTEAL, THORNS, EXECUTE) не показываются, пока не получены; CRIT 0 показан всегда. Похоже, базовые строки: MAX HP, ATTACK, DEFENSE, CRIT, DEF → ATK.
- Стартовые статы на этаже 1 после первой карты STONEBLOOD: HP 100, ATK 12, DEF 20, CRIT 0. Неизвестно, что база, а что дала STONEBLOOD.

### Апгрейды (карты), цвет = редкость
- Зелёный (обычная? или "uncommon"): STONEBLOOD, RECKLESS, BLOODLUST, BLOODBOUND, BARBS, CATCH BREATH.
- Белый (common): LEECH, WHETSTONE, SPARK, DUELIST, PADDING.
- Фиолетовый (rare/epic): ASSASSINATE, EXECUTIONER, RETRIBUTION.
Известные эффекты: RECKLESS: "+22% ATTACK, -12% MAX HP". ASSASSINATE: "+20% CRIT; CRITS HEAL 40% OF DAMAGE". Остальные по смыслу (гипотезы): LEECH = lifesteal, WHETSTONE = +attack, SPARK = +crit, PADDING = +def/HP, BARBS = thorns, EXECUTIONER = execute 26%, BLOODBOUND/BLOODLUST = lifesteal/attack, CATCH BREATH = лечение между боями, RETRIBUTION = thorns, DUELIST = ?.
Карты можно брать повторно (×2). Выбор карты: экран "CHOOSE ONE" с карточками (видно 3 карточки в рамках) + "REROLL - WATCH AD".
Build-экран открывается кнопкой статистики (иконка столбиков справа вверху) с экрана выбора карты; показывает этаж, HP и все взятые апгрейды за забег.
HP переносится между этажами (74/88), бои не восстанавливают полностью.

### Настройки
Music volume (по умолчанию 70%?), SFX volume (80%?), Screen Shake On/Off, Fast Replay (3×) On/Off (ускорение автобоя в 3 раза), QUIT (выход в меню). BACK закрывает. Открывается шестерёнкой справа внизу, доступна и в бою, и на выборе карты.

### Победа
Этаж = 3 врага (3 ромба, "FOE 3/3"). После последнего врага: затемнение + "VICTORY!" / "FLOOR N CLEARED!". Затем выпадает ключ: "+1 GOLD KEY!" с анимацией летящего ключа. Счётчик Keys формата медь/серебро/золото (0/0/1). Тип ключа, вероятно, зависит от этажа или случаен. После этого, видимо, переход на выбор карты.
"Best: —" = лучший этаж (нет рекорда).

### Поражение
"You Died", достигнутый этаж, рекорд, ключи за забег (1 медный, 1 серебряный, 1 золотой к 8 этажу), лидерборд ("RANKING..."), Revive за рекламу (на Poki: rewarded), Main Menu, Play Again (горячая клавиша SPACE).

## 3. Ассеты (плейсхолдеры)
Вырезать из скринов как плейсхолдеры:
- Кнопка-плашка шестиугольная бирюзовая с золотой рамкой (BACK) и вариант с красной рамкой (QUIT, шапка боя и настройки).
- Панель настроек (зелёная текстура + рамка), орнаментальный разделитель (под SETTINGS и на Fail), орнаменты Victory (верх/низ, стрелки по бокам), орнамент над окном Build.
- Кнопки Fail: REVIVE с иконкой видео, прямоугольная с черепом (Main Menu / Play Again).
- HP-бары (рамка со скошенными краями, красная заливка).
- Ромбы-индикаторы врагов.
- Иконки: статистика (столбики в круге), шестерёнка в золотом кольце, ключ золотой (нужны медный и серебряный — перекрасить).
- Фоны: подземелье боя (без героя и UI — придётся генерировать/дорисовывать), фон Fail.
- Герой (бирюзовый плащ), враг "Tiny Mushroom Creature".
CSS (не резать): окно Build (тёмный фон + рамка 1 px), тултипы, тумблеры ON/OFF, слайдеры, все тексты.
Нужна AI-генерация: чистые фоны без UI (бой, Fail), герой в позах (idle, attack, victory, death), враги, ключи трёх типов, текстура панели, при желании орнаменты в высоком разрешении.
Шрифты: Cinzel (или Cinzel Decorative) для заголовков и UI, моноширинный (Courier Prime / VT323-подобный) для HUD боя, готический (UnifrakturMaguntia / Pirata One) для "You Died". Gold gradient + glow через CSS.
