# Промпт: обсуждение звука

Новый чат, рабочая папка — `Projects/DungeonJourney`. **Код и установки пока не делаем** — обсуждаем.

---

Тема чата — звук для DungeonJourney (клон Dungeon Descent, веб-игра для Poki). Идея: локальная нейросеть вытаскивает звуки из записи геймплея оригинала, а мы режем их на отдельные SFX и музыку. Нужно обсудить, реально ли это, и составить список нужных звуков.

Прочитай:
- `CLAUDE.md`;
- `Docs/PLAN.md` — звук относится к этапу 8 «Сочность», но на этапе клона нужны заглушки;
- `Docs/GAME_BRIEF.md`, разделы «Звук», §2–7, — какие события есть в игре;
- `Docs/Analysis/video_*.md` — тайминги событий в видео.

Исходное видео: `Reference/2026-10-21_18-07-33.mp4` (10 мин, AAC 44.1 кГц, стерео). Клипы по событиям — `Reference/Clips/`, тайминги каждого — в `Docs/Analysis/`. ffmpeg установлен через `imageio-ffmpeg` во временном venv, путь уточни у меня, либо предложи постоянную установку.

Что обсудить:
1. **Реально ли это.** Звуковая дорожка, скорее всего, смешанная: музыка + SFX, одновременно может звучать несколько эффектов. Какие варианты есть:
   - разделение источников (Demucs, Spleeter, UVR / MDX-Net и т. п.): отделить музыку от эффектов;
   - поиск событий: детекция всплесков (onset detection) и привязка к таймингам из `Analysis/`;
   - классификация и разметка звуков (например, на основе CLAP или PANNs);
   - нарезка, нормализация громкости, удаление хвостов музыки.

   По каждому варианту: качество на нашем материале, требования (GPU / CPU, вес моделей, Python), сложность. Честно скажи, где результат будет плохим: SFX поверх музыки, короткие перекрывающиеся удары.
2. **Альтернативы**, если чисто вытащить не получится: генерация SFX нейросетью (локально или сервисом), бесплатные библиотеки, синтез простых звуков (jsfxr-подобные). Для каждой — лицензия под релиз на Poki.
3. **Список нужных звуков** по событиям игры. Таблица: событие → звук → откуда взять (видео / генерация / библиотека) → приоритет. Минимум такие:
   - спин карт и остановка карты;
   - hover и выбор карты;
   - реролл;
   - удар, крит, execute, шипы, лечение, вампиризм;
   - урон по герою, смерть врага, смерть героя;
   - AMBUSH и STRIKE FIRST;
   - босс: появление и победа;
   - VICTORY и ключ;
   - открытие ключа, вспышка редкости по редкостям, разбор, мердж, апгрейд;
   - UI-клики;
   - музыка меню и боя.
4. **Правовой момент.** Вырезанные звуки оригинала, как и графика, — только заглушки для клона. В релиз на Poki они не идут. Нужен план замены.
5. **Формат для игры:** форматы и битрейт для веба, общий вес, модуль `../../Modules/audio.ts` — подходит ли он.

Итог чата:
