# Промпт: .gitignore и чистка проекта

Новый чат, рабочая папка — `Projects/DungeonJourney`. Модель — Sonnet: задача механическая, но удаления делать осторожно.

---

Задача: подготовить проект к git. Составить `.gitignore` и почистить проект от временных и неиспользуемых файлов. Сейчас папка проекта **вне git** (в репозитории `AI-Lab` она untracked), поэтому любое удаление необратимо.

Прочитай:
- `CLAUDE.md`;
- `../../Docs/POKI_BASE.md`, раздел «Гигиена проекта»;
- `Docs/PLAN.md`;
- `Docs/ASSETS_SWAP_REPORT.md`;
- `Assets/ASSETS.md`;
- `Config/build.config.mjs` — какие ассеты реально идут в сборку;
- текущий `.gitignore` проекта и `.gitignore` корня репозитория (`../../.gitignore`, если есть).

**Шаг 1 — инвентаризация, ничего не удаляя.** Пройди по проекту (`du`, `find`). Составь таблицу «путь → размер → что это → нужен ли → куда: git / ignore / удалить / спросить». Минимум разбери:
- `node_modules/`, `Build/`, `BuildReport/`, `Cache/`: в ignore, восстанавливаются через `npm install` и `npm run build`;
- venv-окружения (`Tools/audio-venv/` и прочие), `__pycache__/`: в ignore;
- `Assets/_raw/`, старые вырезки, пустые папки, ассеты, на которые нет ссылок ни в коде, ни в `build.config.mjs`. Проверь grep'ом по `Game/` и `Config/`. Вырезки из оригинала, которые ещё используются как заглушки (шестерёнка, баннеры и т. д. — см. отчёт), **не трогать**;
- `Reference/`:
  - исходное видео ~240 МБ, клипы, скрины, `New/` (пак заказчика), `Backup/assets_old.zip`;
  - предложи варианты: всё в ignore и хранить вне git / Git LFS / только лёгкое в git;
  - решение за мной;
- `Docs/Analysis/`, `Docs/Prompts/`, отчёты: в git;
- `Tools/*.py`: в git, кроме одноразовых. Одноразовые перечисли;
- `.claude/`: `launch.json` можно в git, локальные настройки — нет;
- `*.bat`, `package-lock.json`: в git.

**Шаг 2 — моё согласование.** Покажи таблицу и список на удаление с общим весом. Удалять только после моего «да».

**Шаг 3 — выполнение:**
1. Перед удалением чего-то нестандартного (не node_modules, не кэша) сделай архив в `../../_trash/DungeonJourney_<дата>.zip` или в место, которое я назову, и проверь, что он открывается.
2. Удали согласованное. Запиши `.gitignore`.
3. Проверь, что проект восстанавливается с нуля:
   - `npm install`;
   - `npm run build` — билд собирается, вес тот же;
   - `npm test -- stage3` проходит;
   - `git status` показывает только нужные файлы;
   - покажи итоговый размер того, что уйдёт в git.
4. **Не коммить** — коммит сделаю сам или попрошу отдельно.

В отчёте коротко:
- что удалено (с весом);
- что ушло в ignore;
- где лежит архив;
- что осталось под вопросом.

Находки, полезные для других Poki-проектов (типовой `.gitignore`), запиши в «Находки по воркфлоу» в `Docs/PLAN.md`. Сам `../../Docs/POKI_BASE.md` не правь.
