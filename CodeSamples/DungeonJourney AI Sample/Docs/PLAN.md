# PLAN — DungeonJourney

Цель первых этапов (1–6) — полный клон Dungeon Descent по механикам и макету. Отличия DungeonJourney (этап 7) — после клона.

Порядок 3/4 — параллельно. Этапы 5 и 6 поменяны местами (решение заказчика): сначала клон и правки, потом редактор; этажи на этапе 5 правятся в `Game/data/*.json` напрямую.

## Этапы

### 1. ГДД (черновик)
- **Входит:** механики оригинала, структура данных (статы, перки, шмот, враги, сундуки, ключи), логика авто-боя, отличия DungeonJourney (помечены «после клона»).
- **Выход:** `Docs/GAME_BRIEF.md` без пробелов, которые можно закрыть без медиа; список вопросов к медиа.
- **Замораживается:** ничего (черновик).

### 2. Сбор медиа + сверка ГДД
- **Входит:** видео и скриншоты всех экранов и состояний (бой, рулетка, инвентарь, мердж, сундуки, меню, смерть/продолжение), эффекты (всплывающий урон, победа, фейды, тряска, частицы), звуки. Кладутся в `Reference/`.
- **Выход:** ГДД сверен с видео: формулы урона (по цифрам), тайминги боя, полный список перков / шмота / врагов / этажей.
- **Замораживается:** список механик клона.

### 3. Ядро на заглушках
- **Входит:** авто-бой, этажи по конфигу, рулетка перков, инвентарь + мердж, сундуки и ключи, продолжение с этажа, сохранения (localStorage), экраны, отладочная панель.
- **Зависит от:** 2 (формулы); идём по ГДД v0.4, формулы и числа — в конфиге.
- **Не входит:** классы, инвентарь в забеге, развилки (7); VFX/звук сверх заглушек (8); Poki SDK, портрет (9).

#### Архитектура (решено)
- **Рендер — гибрид:** Canvas 2D — сцена боя (фон, герой, враги, числа, частицы, тряска); DOM+CSS — меню, карты, инвентарь, HUD, модалки. Оба слоя — из одной логической сцены 1920×1080 с letterbox. Только ландшафт; в портрете — «поверните устройство».
- **Статы:** `base` + список модификаторов `{stat, op: add|mul|set, value, source}`; итог пересчитывается. REPLACES = `set`; источник (перк / предмет / позже класс) нужен для тултипа в Your Build.
- **Перки, способности врагов, (позже) пассивки классов — один движок хуков**, описанный данными: `{on, if?, do, k...}` + реестр эффектов в коде (`heal`, `bonus_dmg`, `execute`, `thorns`, `lifesteal`…). Хуки: `on_battle_start, on_turn_start, on_before_hit, on_hit, on_crit, on_damaged, on_kill, on_low_hp, on_floor_start, on_floor_end`.
- **Бой:** чистое ядро (без таймеров, RNG с сидом) → лог событий → презентер проигрывает его с таймингами и `timeScale` (Fast Replay ×3, отладка ×10). Headless-прогон для тестов.
- **Этажи — граф с первого дня:** `{version, floors: [{id, nodes: [{id, type: 'fight'|'boss', foes, keyDrop}], edges}]}`; в клоне 1 узел на этаж. Генератор HP/урона даёт стартовые значения, ручные значения в конфиге их перебивают.
- **Шина событий:** типизированный emitter, список в `Game/events.ts` (`hit, crit, execute, thorns, heal, foe_death, boss_death, floor_clear, key_drop, card_spin_tick, card_lock, merge, upgrade, salvage, chest_open, hero_death, revive`).
- **Платформа:** `Game/platform.ts` — заглушки `rewarded()`, `commercialBreak()`, `gameplayStart/Stop()`, `storage`; на этапе 9 меняется только он.
- **Сохранения:** ключ `dj_save`, `{v, meta: {inventory, equipped, keys, shards, best, settings}, run: {floor, perks, hp, seed} | null}`; миграции `migrate[v]`; битый сейв → `dj_save_bak` + чистый старт; запись по событиям.
- **Тексты:** английский, через словарь `strings.en.json`.
- **Ассеты:** нарезанные из `Assets/` сразу, недостающее — цветные заглушки. Шрифты — открытые (OFL) сабсетом через сборку, иначе системные.

**Решения заказчика** (все внесены в бриф):
- Урон = max(1, ATK × крит − 0.5·DEF цели), крит до вычета защиты; защита режет не больше 75% удара.
- Кто бьёт первым — 50/50 перед каждым врагом; после Revive / Continue — герой.
- Дроп ключей: обычный этаж 50% (C/S/G 80/15/5), каждый 5-й 100% (55/35/10), босс 100% (0/50/50).
- Revive — тот же этаж, полное HP; Continue — N−2, полное HP, Fast Replay; QUIT из настроек = поражение.
- Legendary-перки в пуле с малым весом; после босса — гарантированная Epic+ карта.
- Английский через словарь строк; только ландшафт (портрет — этап 9); шрифты OFL (Cinzel, Courier Prime, UnifrakturMaguntia).
- Удар героя — короткий выпад и слэш до врага; враги подбегают; тряска: малая на ударах, сильная на крите / execute / смерти, средняя на победе.
- Фон карт и настроек — размытая сцена боя; кнопки QUIT в HUD нет (выход — шестерёнка).

**Решения по ходу** (внесены в бриф): Choose One — после этажа; `mul` считается от базы + всех `add`; шипы ≤ thornsCap × HP атакующего; предмет в пустой слот надевается сам; Merge — 3 одинаковых → предмет следующей редкости того же слота; Upgrade = цена редкости × (уровень+1), +10% за уровень; Salvage = ◆ редкости + уровень; на You Died — ключи текущей попытки.

## Находки по воркфлоу
- `Modules/build/build.mjs`: лимит 5 МБ (`LIMIT`) зашит; для веб-игр (Poki) нужен `CFG.sizeLimit` (2026-10-23, этап 8).
