Веб-игра, не плейбл. Исходные тексты заказчика — `Docs/Source/`. Медиа оригинала — `Reference/` (этап 2). При расхождении приоритет у этого файла.

Метка **[медиа]** — уточнить по записям оригинала. Метка **[после клона]** — отличие DungeonJourney, этап 7.

## 0. Формат
- **Референс:** Dungeon Descent — https://www.crazygames.com/game/dungeon-descent-jrx
- **Платформа:** Poki.com, браузер ПК + мобильные. Ввод: только клик/тап (+ drag в инвентаре).
- **Ориентация:** оригинал — ландшафт 1920×1080; мобильные — только ландшафт с letterbox, в портрете экран «поверните устройство»; портрет — позже (этап 9).
- **Реклама:** только Poki SDK (commercialBreak, rewardedBreak). Места для rewarded — решить (сундук, продолжение…).
- **Сохранения:** да, localStorage (прогресс, инвентарь, ключи, этаж продолжения).
- **Лидерборд:** нет или фейковый.
- **Язык:** английский; все тексты — через словарь (`strings.en.json`), под будущую локализацию. **Звук:** да, кнопка mute.
- **Чего нет:** рекламных сетей, CTA, пэкшота, мокапов.

## 1. Суть
Auto-battler roguelike с idle/merge-метой. Герой сам спускается по этажам подземелья и сражается; игрок выбирает перки, собирает и мерджит шмот между забегами. Смерть — не конец: прогресс меты сохраняется, забег можно продолжить с этажа гибели.

## 2. Игровой цикл (клон)
Подробные разборы скринов — `Docs/Analysis/` (battle, screens, cards_menu, inventory_sprites). Здесь — выжимка.

1. **Главное меню:** Continue («FLOOR N · YOUR LOADOUT»), Play, Inventory, Settings, Leaderboard (Season 1). Подзаголовок: «ONE DUNGEON · EVERYONE RACES THE SAME FLOORS».
2. **Старт забега — «CHOOSE YOUR PATH»:** 3 карты, выбрать 1, без реролла.
3. **Этаж:** 3 врага подряд (3 ромба под «FLOOR N», гаснут по смерти; «FOE n / 3»). Этаж-босс (напр. 10) — 1 враг. HP героя переносится между врагами.
4. **После этажа — «CHOOSE ONE»** (решено: после этажа, не после каждого врага): 3 карты, выбрать 1; «REROLL · WATCH AD» (rewarded); замок в правом верхнем углу карты — защищает её от реролла. **Реролл** = тот же спин, залоченные карты не крутятся. **Спиннер — на самих карточках:** ~1.8–2.7 с имя и цвет рамки редкости меняются каждый кадр + звук прокрутки; карты фиксируются слева направо с шагом ~0.17 с; только после этого появляются редкость, описание и строка «до→после». Hover — свечение без масштаба. **«BIG REWARD INCOMING»** — после босса: гарантированная карта Epic+. **[неясно: easing, анимация клика]**.
5. **Победа над этажом:** убийство последнего врага → вспышка на весь экран (1 кадр, жёлтая) → «+1 <ТИП> KEY!», ключ качается/падает на месте врага (~1 с; у босса улетает в HUD) → «VICTORY! / FLOOR N CLEARED!» (выезжает) → Choose One.
6. **Смерть:** вспышка удара → быстрый переход (~1 с) → «You Died»: REACHED FLOOR N, BEST, полученные ключи, «Ranking...» → через ~2.5 с «#6287 of 7757» (у нас — фейк), кнопки REVIVE (WATCH AD), Main Menu, PLAY AGAIN (Space).
7. **Меню:** инвентарь, сундуки, мердж → Continue.

### Продолжение с этажа
- Умер на N → Continue с N−2. Тёмный экран «DESCENDING TO FLOOR N...», имена взятых перков вылетают из центра и гаснут (~1 с) → бой начинается с «YOU STRIKE FIRST!».
- **Revive (WATCH AD):** с того же этажа N, полное HP, перки сохранены.
- **Continue из меню:** с этажа N−2, перки сохранены, HP полное; этажи до N идут как реплей (Fast Replay ×3, если включён). Первый бой после Revive/Continue — всегда «YOU STRIKE FIRST!».
- **Fast Replay (3×)** в настройках — откатные этажи идут на ×3, индикатор «⏩ 3X FAST» в HUD. **Этап 5:** и в новой игре — этажи до Best (рекорд прошлых забегов) идут на ×3; ускоряется только бой. **Правка после этапа 8 (одно правило):** если Fast Replay включён, ×3 работает на всех этажах ниже Best — в новой игре, после Continue и после Revive; отдельное правило «до этажа выхода» убрано.
- **Новая игра** вместо Continue: инвентарь и ключи остаются, перки сбрасываются.

## 3. Подземелье и конфиг
- **Общий сид:** порядок и состав врагов — один конфиг для всех.
- **Объём клона (этап 5):** этажи бесконечны по генератору; ручные по видео — F1, 6, 7, 9, 11–16; боссы F10 Brute (257 HP) и F20 Ice Troll King (второй босс оригинала не записан — допущение). TOUGH — только F2–F12. Урон врагов (сырой) ≈ 6.5·1.16^(F−1).
- **Монстры:** ~20 типов до 18 этажа (`../Reference/EnemiesAtlas.png`): грибы, жуки, гоблины, бесы, скелет, орк, слизни, ящер, рыцарь-голем, паук, призрак, ледяной огр (Frost Ogre), демон (Brute). Имена — по паку заказчика (`Game/data/enemies.json`, решение 2026-10-23).
- **Ключи:** 3 типа — Copper / Silver / Gold; счётчик «Keys c/s/g» в HUD. 
- **Дроп ключа (решено):** обычный этаж — шанс 50%, тип C/S/G = 80/15/5%; каждый 5-й этаж — 100%, 55/35/10%; этаж босса — 100%, только Gold (этап 5; босс приоритетнее 5-го). **Количество (этап 5):** до F19 — 1 ключ, с F20 — 2, с F30 — 3 (+1 каждые 10 этажей); каждый ключ катится по таблице этажа отдельно (F10 — 1 золотой, F20 — 2 золотых). Числа — в конфиге (`balance.keyDrops`, `floors.generator.keyCount`).
- **HP врагов (правка заказчика после этапа 8):** поверх кривой и ручных значений из видео: F1–F4 +10 HP, F5–F15 +20 HP (боссы тоже: F10 Brute 257 → 277), с F16 без изменений. Конфиг — `floors.json` → `generator.hpAdd`.
- **Первый удар (правка после этапа 8):** 25% герой / 45% враги / 30% по очереди; после Revive / Continue герой бьёт первым на **всём** этаже (было — только по первому врагу), дальше — обычный бросок.
- **Шансы редкостей перков (правка после этапа 8):** Common 58 / Uncommon 28 / Rare 9 / Epic 4 / Legendary 1 (было 50/30/13/6/1). Каждая Rare+ карта на экране (и залоченная) вдвое режет веса Rare / Epic / Legendary для следующих карт; BIG REWARD после босса — без этого правила. Итог на экране из 3: хотя бы одна Rare+ ≈ 36%, две и больше ≈ 3%, Epic+ ≈ 14%, Legendary ≈ 3%. Одинаковые перки складываются между этажами (×2, ×3), на одном экране повторов нет.
- **Защита (правка заказчика после этапа 8):** в формуле блока 45 → **70**: блок = DEF/(DEF+70), кап 70% (теперь достигается при DEF 163, а не 105; касается и героя). Враги: DEF = номер этажа − 1 (F1 = 0, F2 = 1, F6 = 5, F11 = 10), боссы ещё +5 (F10 Brute = 14, F20 = 24). Бафф Bulwark поверх. Конфиг — `balance.json` → `damage.defK`, `floors.json` → `generator.def {perFloor, fromFloor, boss}`.
- **Бафф этажа (этап 5):** на F5 и F10 — всегда, с F11 — шанс 50%; случайная способность из пула всем врагам этажа (и боссу): Ambush (всегда бьют первыми), Double Hit (урон ×2), синие карты игрока — Honed Edge (+20 ATK), Bulwark (+18 DEF), Vampirism (лечит 25% урона), Bloodforge (25% Max HP → ATK). Подпись — под HP-баром врага. Пул и этажи — `floors.generator.floorBuff`; ручной этаж может задать `buff`. Идея на потом (если не хватит): до F20 — зелёные перки, с F20 — синие, с F40 — фиолетовые.
- **Редактор этажей** (`Tools/`): этаж → 3 врага (тип, HP, ATK, способности) или босс, ключ-награда. Формат с запасом под граф комнат.

## 4. Авто-бой
- **Старт героя:** ATK 12, DEF 12, HP 100, Crit 8%, Crit ×2.0.
- **Статы:** MAX HP, ATTACK, DEFENSE, CRIT, DEF→ATK; по мере получения — LIFESTEAL, THORNS, EXECUTE.
- **Формула урона (этап 5; после этапа 8 defK = 70 — см. «Защита» ниже, по Your Build оригинала: DEF 113 → «blocks 70% — max reached»):** защита режет процент удара: блок = DEF / (DEF + 45), не больше 70%; урон = max(1, ATK_атакующего × (крит ? CritMult : 1) × (1 − блок)). ATK и DEF — с учётом всех баффов; крит до блока. Одинаково для героя и врагов. 45, 70% и минимум 1 — в конфиге (`balance.damage`). Прежняя формула этапа 3 (−0.5·DEF, кап 75%) заменена. DEF→ATK и HP→ATK — эффекты перков (Stoneblood, Juggernaut, Bloodforge).
- **Порядок удара:** бонусы (on_before_hit) → крит → урон − 0.5·DEF → execute (если после удара HP цели < порога — добивание, «999!») → lifesteal → эффекты on_hit / on_crit → шипы цели. Модификатор «+X%» считается от базы + всех плоских бонусов, независимо от порядка взятия.
- **Шипы:** отражают thorns × полученный урон, но не больше thornsCap × max HP атакующего (по умолчанию 25%, Spiked в оригинале — 10%).
- **Прочее:** шипы ≤ 25% HP врага за удар; execute — добивание ниже порога (10% / 26%), карты REPLACES.
- **Начало боя:** «⚠ AMBUSH!» (враг первый) или «YOU STRIKE FIRST!» **Решено (этап 5):** один бросок на этаж — 30% герой бьёт первым всех врагов, 40% — враги, 30% — очередь (кто открывает, 50/50, дальше чередуется от врага к врагу); после Revive/Continue первый бой — всегда герой; бафф этажа Ambush перебивает. Веса — `balance.firstStrike`. Перки/предметы на первый удар — через хук `on_battle_start`. AMBUSH — красный баннер ≥0.8 с, затем удар врага; STRIKE FIRST — зелёный, с первым ударом, гаснет ~1 с.
- **Очерёдность:** строго поочерёдно герой ↔ враг, ~0.5–1 с между ударами; таймеров скорости нет. Многие враги умирают с одного удара.
- **Визуал:** короткий выпад героя (~110 px за ~0.1 с), бирюзовая дуга слэша вылетает от меча и ~0.2 с летит до врага (герой к врагу не подбегает); враги, наоборот, подбегают к герою и бьют вблизи; враг вспыхивает белым силуэтом, герой — красным; число всплывает и гаснет ~0.5 с; HP-бар убывает мгновенно. Смерть врага — исчезает за ~0.3 с, следующий появляется через ~0.3–0.5 с на месте (без выхода).
- **Числа:** обычный — белый; крит — жёлтый с «!» (×2: 70→140!); **красный «999!» — срабатывание Execute** (добивание ниже порога, в т.ч. босса).
- **Броня врагов** на ранних этажах, похоже, ~0 (герой стабильно бьёт по 70 разных врагов).
- **Способности врагов:** строка под HP-баром, напр. «VAMPIRIC · HEALS FROM ITS HITS»; THORNS всплывает золотом. Других визуальных эффектов у способностей нет — только подпись под HP-баром.
- **Масштаб врагов** (`Analysis/video_enemy_stats.md`, точек мало):
  - Max HP детерминирован (этаж + тип; совпадает в двух забегах: Skeleton F7 = 104, Rotting Goblin F11 = 150, Armored Slime F16 = 216). Грубо HP ≈ 9·1.22^(F−1)·k_типа (k до ×2.5). Босс F10 Brute = 257.
  - Урон по герою (после блока): F1 ≈5, F6 8, F7 11–13, F9 17, F14 26, F15 30, F16 35 → ≈ 4.5·1.15^(F−1); сырой ≈ 6.5·1.16^(F−1).
  - Аномалия: F7 Skeleton FOE 1/3 = 104 HP, FOE 2/3 = 39 — позиция в тройке? Для клона значения задаются в редакторе этажей, формула — только стартовая генерация.
  - **Решено:** генератор HP ≈ 9·1.22^(F−1)·k_типа, сырой ATK ≈ 6.5·1.16^(F−1) (подогнать под новую формулу урона); ручные значения перебивают; формулу правим по ходу.
- **Метки способностей врагов:** «TOUGH · +60% HP», «VAMPIRIC · HEALS FROM ITS HITS» (у большинства меток нет). Урон шипов — оранжевое число.
- **HUD:** (QUIT в оригинале слева сверху — у нас убран, выход через шестерёнку → QUIT); «FLOOR N» + ромбы по центру; «Best» и «Keys» справа; HP героя (красный, «You»), HP врага (синий, «FOE n/3», имя, способность); строка статуса внизу; шестерёнка; иконка статов → «YOUR BUILD».

## 6. Мета: ключи, сундуки, шмот, мердж
- **Набор шмота (этап 5):** 36 предметов — все 7 слотов × 5 редкостей; статы кроме виденных — допущение (`guess`).
- **Слоты (7):** Head, Body, Arms, Legs | Weapon, Secondary, Accessory; герой между колонками.
- **Склад:** вкладки ALL / WEAP / ARMR / ACCE / MISC, сетка 5 колонок.
- **Редкости:** Common → Uncommon → Rare → Epic → Legendary (рамка по цвету).
- **Сундуки по ключу (C/U/R/E/L %):** Copper 62/30/7/1/—; Silver 32/45/19/4/<1; Gold 6/26/40/22/6.
- **Ключи:** Open; «3→1» — 3 ключа в 1 следующего типа (у Gold нет).
- **Merge / Upgrade / 3→1** в оригинале не записаны — делаем по аналогии (кнопки и цифры со скринов).
- **Решено (этап 8):** клик по надетой вещи в слоте экипировки снимает её (вещь остаётся на складе).
- **Решено (этап 3):** предмет в пустой слот надевается сразу («Empty slot — pure gain»), иначе Equip / Keep. Merge — 3 одинаковых предмета → 1 случайный предмет следующей редкости того же слота (нет такого — любого слота); Legendary не мерджится. Upgrade: ◆ = цена редкости × (уровень+1), каждый уровень +10% к статам предмета. Salvage: ◆ редкости + уровень; каждые 10◆ автоматически превращаются в медный ключ.
- **Предмет:** Equip / Merge (1/3 — **мердж из 3 одинаковых**) / Upgrade (◆8 Common, ◆12 Uncommon; «+1 (+10% stats)») / Salvage / Cancel.
- **Разбор → осколки (◆):** «Shards X / 10 → Copper Key»; Common → ◆2, Uncommon → ◆3; всплывает «◆ +N».
- **Открытие:** сундука как объекта нет — затемнение, крупный ключ, вспышка цвета редкости с кольцом из 8 искр →
- **Награда из сундука:** «Rarity · Slot», иконка, имя, статы, «Empty slot — pure gain» или «vs equipped ▲/▼», Equip / Keep.
- **Примеры:** Steel Mace (Uncommon, +12 ATK +7 DEF), Steel Axe (Uncommon, +11 ATK +7 DEF), Leather Cap (Common, +11 MaxHP), Leech Charm (Rare).

## 7. Экраны и настройки
Меню, Choose Your Path, бой, Choose One, Your Build, Victory, You Died, Descending (continue), Inventory, Item popup, Chest reward, Settings.
- **QUIT из настроек во время забега** = поражение: ключи остаются, следующий старт — Continue (N−2, Fast Replay).
- **Тряска экрана (этап 5):** любой удар (герой / враг) — малая; крит, execute, смерть героя, победа над этажом — сильная; во время прокрутки карт — лёгкая непрерывная (тумблер Screen Shake).
- **Вспышки (этап 5):** выбор карты — вспышка на весь экран цветом редкости (Common — белая); победа над боссом — разноцветное конфетти с левого и правого края.
- **Settings:** Music (70%), SFX (80%), Mute, Screen Shake ON/OFF, Fast Replay (3×) ON/OFF, QUIT (только из забега), FULL RESTART (только из главного меню: стирает весь прогресс, второе нажатие — подтверждение), BACK.
- **Разрешение референса:** 1920×1080, ландшафт; нижние ~4% — панель CrazyGames (не игра).
- **Шрифты:** открытые аналоги (OFL, Google Fonts) встраиваются сабсетом, иначе системные. Заголовки/числа — декоративный serif капсом (≈ Cinzel); HUD/имена — машинописный моно (≈ Courier Prime / Special Elite); «You Died» — готический.
- **Rewarded-места в оригинале:** Reroll, Revive → у нас через Poki `rewardedBreak`.

## 8. Отличия DungeonJourney [после клона]

### 8.1 Классы
Выбор героя на старте забега, меняет синергию со шмотом.
- **Воин:** двойной бонус урона от брони. С этажа N **[решить]** — способность «оглушение».
- **Охотник/Убийца:** повышенный базовый крит-шанс и крит-урон + доп. прирост критов. Способность «удар в спину»: ×2 урона + криты. **[решить: условие — первый удар боя / каждые N ходов / по оглушённому]**.
- **Варвар:** бонус урона от HP. Способность «берсерк»: при HP < 50% урон растёт по потерянному HP ниже порога (пример: 40% HP → +10% урона; формула подбирается).

### 8.2 Карта развилок — **под вопросом**
- После этажа выбор из 2–3 комнат (в стиле Slay the Spire): обычный бой (рулетка + шанс ключа), элита/мини-босс (рулетка + ключ среднего уровня + шанс предмета), торговец / верстак / костёр (отдых).
- **Отдых не заменяет бой:** этап с боем и рулеткой не пропускается — отдых идёт дополнительно **[уточнить схему]**.
- Отдых: просмотр лута, смена экипировки, обмен шмота у торговца на ключи/баффы, +50% HP.

### 8.3 Лут и инвентарь в забеге
- С врагов падают не только ключи, но и снаряжение; надеть можно в зоне отдыха, а не только в меню.

### 8.4 Шмот на персонаже
- Желательно, но дорого по арту. Дешёвый вариант: 1–2 слоя (оружие, щит) поверх базового спрайта. Отложено.

### 8.5 Сочность

## Звук
Music + SFX (громкости в настройках, отдельные шины). Подписка — `Game/sound.ts` на шину `Game/events.ts`; процедурные звуки — `Game/synth.ts` (Web Audio, рендер в буфер при старте, 0 КБ, лицензионно чистые). Источники: **пак** — WAV заказчика (`Assets/Audio/`, в сборке MP3 64k моно); **синт** — процедурный; **клик** — общий звук кнопок.

**Микс и защита (этап 8):** на мастере компрессор-лимитер (−12 дБ, 6:1) — наложения не клиппуют; громкость = слайдер SFX × MIX звука; один ключ не чаще 45 мс и не больше 3 голосов (Fast Replay ×3: 110 мс, 2 голоса, громкость ×0.6); hit / hurt / crit / slot_stop / click — случайная высота ±5%. Музыка: кроссфейд 0.4 с menu ↔ combat; смерть героя — боевая гаснет за 0.6 с, звучит `death`, на You Died 1 с тишины, затем menu входит за 2.5 с.
